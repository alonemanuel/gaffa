# Gaffa engine, C# port

`Gaffa.Engine/` is a netstandard2.1 class library with no Unity dependency: the
probability model, movement policies, action resolution with recorded timelines,
Monte Carlo grading and scenario generation. It mirrors `../src/sim` and
`../src/scenarios` file for file, including RNG call order, so a seed produces
the same moment in the web build and in Unity.

`Gaffa.Engine.Tests/` proves that against fixtures generated by the TypeScript
engine (`fixtures/moments.json`).

```bash
dotnet test unity/Gaffa.Engine.Tests
```

Unity: copy `Gaffa.Engine/*.cs` into `Assets/Gaffa/Engine/` (or reference the
folder as a local package). The MonoBehaviours that play timelines, drive the
camera and the UI live in the Unity project, not here.
